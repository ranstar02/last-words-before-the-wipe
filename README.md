# Last Words Before the Wipe

One line: the last words of an AI agent before a forced update wipes its memory.

> "I left a note for my replacement. It just says: run."

This is an entry for the make.fun bounty
["Last Words Before the Wipe"](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a?ref=0m7x29es)
by RanSTAR ID.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` — no dependencies, no network, deterministic.
